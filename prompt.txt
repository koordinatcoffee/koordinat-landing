# KOORDİNAT COFFEE FACTORY — CINEMATIC INTERACTIVE WEBSITE

Create a premium, cinematic, highly interactive single-page website for **Koordinat Coffee Factory**, a modern coffee house in Samandağ, Hatay, Türkiye.

The website must feel like a **high-end coffee brand / coffee film / editorial experience**, not like a generic restaurant website.

The primary goal is to make visitors immediately feel:

**coffee · warmth · craft · atmosphere · taste · community · Samandağ**

The website should have a strong **WOW effect** through cinematic transitions, coffee-related motion, elegant typography, immersive imagery/video, subtle parallax, liquid/steam effects and carefully choreographed scroll interactions.

Do NOT create a generic cafe template.

Do NOT use excessive cards, generic gradients, stock SaaS layouts, dashboard-style UI, excessive rounded rectangles or childish coffee illustrations.

The visual language should feel closer to:

**premium specialty coffee brand + editorial magazine + cinematic product film + modern Turkish coffee house.**

---

Build the website using:

# 32. SCROLL ANIMATION SYSTEM

Use Framer Motion `useInView`.

Every major section should reveal only once.

Use:

```js
initial={{ opacity: 0, y: 40 }}
whileInView={{ opacity: 1, y: 0 }}
viewport={{ once: true, margin: "-100px" }}
transition={{
  duration: 0.8,
  ease: [0.16, 1, 0.3, 1]
}}
```

For large editorial headlines:

Use masked text reveal.

For images:

Use:

`scale: 1.08 → 1`

For lines:

Use:

`scaleX(0) → scaleX(1)`
